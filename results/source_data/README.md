# Figure and table Source Data

This directory contains the final numerical values underlying figures and
tables in the associated manuscript. These are chart-facing summaries and
selected per-context diagnostic outputs, not the raw or curated Mayr/ESNUEL
training datasets and not a substitute for those datasets.

The CSV files and their JSON manifests are supplied to support inspection and
reproduction of the reported figures and tables. Author-generated numerical
results may be reused with attribution to the archived release and associated
article. Any third-party-derived molecular identifiers, literature facts, or
source metadata remain subject to the terms of their original sources; no
additional rights in those fields are granted here.

The underlying curated datasets are available only through the request route
and rights review described in `../../DATA_AVAILABILITY.md`.
